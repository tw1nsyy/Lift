# Лидерборд LIFT: настройка (один раз, ~5 минут)

Нужен только браузер и аккаунт Google. Платный аккаунт Apple не нужен.

## Часть 1. База данных (делает один из вас)
1. Открой console.firebase.google.com и войди в Google.
2. **Create a project** (Добавить проект) → имя, например `lift-board` → Google Analytics выключи → **Create project**.
3. Слева **Build → Realtime Database → Create Database**.
4. Выбери любую локацию (например Belgium, `europe-west1`) → режим **Start in locked mode** → **Enable**.
5. Вкладка **Rules** → удали всё → вставь содержимое файла `database.rules.json` из этой папки → **Publish**.
6. Вкладка **Data**: наверху будет адрес вида `https://lift-board-default-rtdb.europe-west1.firebasedatabase.app`. Скопируй его.

Если Firebase просит привязать банковскую карту или перейти на тариф Blaze, остановись и ничего не вводи, напиши мне.

## Часть 2. В приложении (создатель группы)
1. **Сегодня → Лидерборд → Настроить лидерборд**.
2. Режим **Создать группу**: впиши имя, вставь адрес базы, нажми **Сгенерировать** для кода группы → **Подключиться**.
3. Нажми **Пригласить друга**: отправь другу сообщение с кодом приглашения.

## Часть 3. В приложении (друг)
1. **Сегодня → Лидерборд → Настроить лидерборд**.
2. Режим **Вступить в группу**: впиши имя, вставь код приглашения → **Подключиться**.

## Как это работает
- Данные отправляются при запуске приложения и после каждой завершённой тренировки. Потяни экран вниз, чтобы обновить.
- Передаются: имя, число тренировок, объём, лучший расчётный 1ПМ по упражнениям. Демо-данные не передаются.
- Код группы работает как пароль: правила базы не дают просматривать список групп, нужно знать код.
- Результаты никто не проверяет.
